# Historische Dokumente

Diese Dateien bewahren frühere Konzepte, Quellenlisten und Katalogstände. Sie sind **keine aktuelle Funktionsbeschreibung oder medizinische Freigabe**. Aussagen zu Live-dm, Poren-Scores, garantierter Verträglichkeit, alten Startskripten oder Produktzahlen können überholt sein.

Die gepflegte Anleitung steht in [../../README.md](../../README.md), aktuelle Befunde in [../reviews/](../reviews/). Referenz-CSV-Dateien liegen in `data/`; tatsächlich geladene Kataloge in `../../data/`.
