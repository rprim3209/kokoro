## Filter

Behalten:

- `category = face/skincare` (inkl. Markenseiten-verifizierte DE-SKUs)
- plus ein paar `other`, deren Name klar Gesicht ist (z. B. Nettoyant Visage, Photoderm, Weleda Fluide)

Raus: Haar, Deo, Dusche, Seife, Intim, Baby-Wipes, Makeup, Parfum, CFI-Marken ohne Produkt.

`keep_reason` sagt, warum die Zeile blieb.
